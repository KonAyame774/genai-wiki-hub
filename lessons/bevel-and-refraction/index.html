物理厚度、倒角光線與 Vista 鏡面切面

拆解 Windows Vista Aero 的靈魂密碼——用不對稱 border、雙層 inset 陰影、50% 高光階躍與文字光暈打造真實玻璃厚度。

TL;DR 一句話核心觀念

真正有「玻璃感」而不是「透明紙」的關鍵，在於 邊緣厚度與表面鏡面反射。透過「上左高光、下右微暗」的四邊不同透明度邊框＋inset 0 1px 0 0 rgba(255,255,255,0.8) 1 像素切角、.glass-panel::before 上半部 50% 鏡面反光階躍，以及 .vista-text 白色保護光暈，就能精準復刻 Vista Aero 經典的立體晶瑩感。

🧩 核心觀念拆解

TECHNIQUE 01

物理厚度與光學倒角（Optical Bevel）

  • 不對稱受光邊框：假設光源來自左上方，將 border-top-color（0.7）與 border-left-color（0.5）調亮，其餘維持極淡 0.2。
  • 1 像素精準切角：疊加 inset 0 1px 0 0 rgba(255,255,255,0.8) 上緣高光線與 inset 0 -1px 0 0 rgba(0,0,0,0.1) 下緣暗角。
border: 1px solid rgba(255,255,255,0.2);
border-top-color: rgba(255,255,255,0.7);
border-left-color: rgba(255,255,255,0.5);
box-shadow: 0 20px 40px rgba(0,0,0,0.2),
  inset 0 1px 0 0 rgba(255,255,255,0.8),
  inset 0 -1px 0 0 rgba(0,0,0,0.1);
TECHNIQUE 02

表面折射與 50% 鏡面高光切面

  • 非連續階躍光斑：在 .glass-panel::before 設 height: 50%，直接於視窗腰部切出水平鏡面反光分界線。
  • 點擊穿透鐵則：偽元素務必設定 pointer-events: none; 且父容器須設 overflow: hidden，防止遮擋互動元素。
.glass-panel::before {
  content: ""; position: absolute;
  top: 0; left: 0; right: 0; height: 50%;
  background: linear-gradient(180deg,
    rgba(255,255,255,0.4) 0%,
    rgba(255,255,255,0.05) 100%);
  pointer-events: none;
}
TECHNIQUE 03

Vista 風格的文字防護光暈

  • 高對比背景威脅：當半透明面板滑過深色圖案或暗色區塊上方，深色標題（#1c1c1e）會瞬間失去對比度。
  • 白色雙層光暈：透過兩圈不同擴散半徑（8px / 16px）的白色 text-shadow，替文字建立專屬發光防護層。
.vista-text {
  color: #1c1c1e; font-weight: 600;
  text-shadow:
    0 0 8px rgba(255, 255, 255, 0.9),
    0 0 16px rgba(255, 255, 255, 0.5);
}

⚠️ 常見誤區：加上 ::before 鏡面切面後，卡片裡的按鈕點不到了！

絕對定位的 ::before 偽元素預設會吃掉上半部 50% 區域的滑鼠點擊事件！在實作任何覆蓋式高光或雜訊層時，一定要加上 pointer-events: none;，並讓內部文字／按鈕擁有 position: relative; z-index: 1;。

📝 隨堂自我檢測（點擊選項立即批改）


      

        

          
Q1. 為何 .glass-panel 通常將 border-top-color 與 border-left-color 設為較高不透明度（0.7 / 0.5），而右邊與下邊維持極低不透明度？

          

            
            
            
            
          

          

            ✅ 解析（正解：B）：迎光面（左上方）高光、背光面（右下方）微暗，能用純 CSS 邊框低成本塑造出玻璃切角的立體厚度。
          

        


        

          
Q2. 製作 Vista 經典「上半部 50% 鏡面反光切面」的 ::before 偽元素時，為何一定要加上 pointer-events: none;？

          

            
            
            
            
          

          

            ✅ 解析（正解：B）：設定 pointer-events: none; 可讓所有滑鼠點擊與選取操作穿透反光層，直達底下的互動元件。
          

        


        

          
Q3. .vista-text 使用 text-shadow: 0 0 8px rgba(255,255,255,0.9), 0 0 16px rgba(255,255,255,0.5) 的主要設計目的為何？

          

            
            
            
            
          

          

            ✅ 解析（正解：B）：雙層白色光暈把深色字元與雜亂或深色的底層背景隔開，讓視窗文字永遠清晰可讀。
