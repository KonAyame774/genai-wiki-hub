WCAG 對比度驗證與無障礙降級策略

兼顧極致通透與全民可讀性——實測 WCAG 2.2 相對亮度對比，並用 prefers-reduced-transparency 與 @supports 打造安全退場防線。

TL;DR 一句話核心觀念

真正成熟的光學設計必須經得起極端閱讀環境考驗：將閱讀區底色墊高以穩守 WCAG 2.2 4.5:1（AA 級） 文字對比底線，並同時撰寫 @media (prefers-reduced-transparency: reduce) 與 @supports not (backdrop-filter: blur(1px)) 雙重無障礙退場規則。

🧩 核心觀念拆解

TECHNIQUE 01

WCAG 2.2 對比度紅線（AA / AAA）

  • 三大關鍵數字：一般內文最低 4.5 : 1（AA 級）、大標題（>= 18pt）最低 3.0 : 1、高齡與醫療 AAA 級目標 7.0 : 1。
  • 實務墊底建議：外層做玻璃透視，內層文字卡建議設在 rgba(255,255,255,0.58～0.75)。
Contrast = (L1 + 0.05) / (L2 + 0.05)
/* 一般文字須 >= 4.5 : 1 */
TECHNIQUE 02

系統「減少透明度」媒體查詢

  • 尊重系統輔助偏好：當使用者在 Windows 11 或 macOS 開啟「減少透明度」時，自動撤銷即時模糊。
  • 高不透明度退場：改用 rgba(248, 250, 252, 0.94) 潔淨霧面實底，對比度瞬間拉升至 10:1 以上。
@media (prefers-reduced-transparency: reduce) {
  .glass-panel {
    backdrop-filter: none;
    background: rgba(248, 250, 252, 0.94);
  }
}
TECHNIQUE 03

不支援模糊環境的 @supports 保底

  • 防禦性退場（Progressive Enhancement）：防止舊版瀏覽器或低階模式在沒有模糊效果時讓背景雜線直接透穿文字。
  • 一鍵保底寫法：利用 @supports not 將底層白霧安全抬高至 0.90。
@supports not ((backdrop-filter: blur(1px))
  or (-webkit-backdrop-filter: blur(1px))) {
  .glass-panel {
    background: rgba(248, 250, 252, 0.90);
  }
}

⚠️ 常見誤區與無障礙地雷：別把「白光外框 text-shadow」當作唯一救命稻草！

.vista-text 雖然能在深色圖塊上提升主觀視覺邊界，但 WCAG 自動化稽核只計算文字色（#1c1c1e）與半透明合成後背景的平均相對亮度。如果卡片底色只有 0.12 且剛好蓋在深藍背景上，對比度依舊會不及格！務必靠實底白霧濃度站穩 4.5:1。
