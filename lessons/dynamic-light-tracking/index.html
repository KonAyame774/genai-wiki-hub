動態光源追蹤與滑鼠高光跟隨

讓靜態毛玻璃「活過來」——透過 --mx / --my CSS 變數與 pointermove，打造 Apple Liquid Glass 級游標即時反光與邊緣感光。

TL;DR 一句話核心觀念

Apple Liquid Glass 強調玻璃能隨使用者動作即時回饋光影：只需數行 JS 監聽 pointermove 並將座標寫入 --mx / --my，搭配 radial-gradient(circle at var(--mx) var(--my), ...) 與外框遮罩，即可在零 Layout Reflow 下讓玻璃表面與倒角邊緣追蹤發光。

🧩 核心觀念拆解

TECHNIQUE 01

CSS 自訂屬性驅動表面高光

  • 座標換算：以 e.clientX - rect.left 取得相對於卡片左上角的像素座標寫入 --mx、--my。
  • 不可忽略 Fallback：宣告 var(--mx, 50%) var(--my, 20%)，確保手機無懸停游標時也能維持美觀受光態。
background: radial-gradient(
  260px circle at var(--mx, 50%) var(--my, 20%),
  rgba(255, 255, 255, 0.42) 0%,
  transparent 72%
);
TECHNIQUE 02

Border-Mask 倒角邊緣感光

  • 只點亮外框 1.5px：利用雙層遮罩互斥（mask-composite: exclude）挖空內部文字區，只在細窄邊框透出隨滑鼠滑動的白光。
  • 視覺不刺眼：高光集中於玻璃切角，中央內文對比度依然保持清晰。
padding: 1.5px;
-webkit-mask:
  linear-gradient(#fff 0 0) content-box,
  linear-gradient(#fff 0 0);
-webkit-mask-composite: xor;
mask-composite: exclude;
TECHNIQUE 03

零 Reflow 與 60fps 節流紀律

  • 嚴禁改幾何屬性：絕不修改 top/left/width；若做 3D 微傾角，僅用純 GPU 合成的 transform: perspective() rotateX() rotateY()。
  • 效能極限 < 0.5ms：務必替追光層設定 pointer-events: none;，避免事件彈跳與閃爍。
transform: perspective(900px)
  rotateX(var(--rx, 0deg))
  rotateY(var(--ry, 0deg));

⚠️ 常見誤區與效能地雷：切勿在追光浮層重複套用 backdrop-filter！

追光效果的本質是「高光反射貼層」，完全不需要也不應該再掛一次 backdrop-filter。若在卡片內部的追光層加上模糊濾鏡，游標每移動 1 像素就會強迫 GPU 重新取樣模糊一次，直接違反 AGENTS.md 合成圖層預算！

📝 隨堂自我檢測（3 題）

      

        

          
Q1. 為何在撰寫 radial-gradient(260px circle at var(--mx, 50%) var(--my, 20%), ...) 時，建議加上預設值（Fallback）？

          

            
            
            
            
          

          
✅ 解析（正解：A）：手機用戶通常不具備 hover 游標位置；保留 50%, 20% 回退座標可保證卡片在任何裝置皆維持精緻反光。

        


        

          
Q2. 製作「只有玻璃外框 1.5px 邊緣會隨游標發光、中間內容不被蓋住」最適合搭配哪一項 CSS 技術？

          

            
            
            
            
          

          
✅ 解析（正解：A）：遮罩互斥能精準扣掉內文區，只留下 padding 寬度的邊框顯示徑向光斑。

        


        

          
Q3. 實作滑鼠追光反光與微幅 3D 傾角回饋時，應如何避免造成瀏覽器卡頓（Layout Thrashing）？

          

            
            
            
            
          

          
✅ 解析（正解：B）：transform 與自訂屬性背景繪製不會觸發主執行緒重新排版，能輕鬆保持 60fps。
