SVG 置換濾鏡與邊緣色散折射

突破 blur() 的平面極限——運用 <feDisplacementMap> 像素偏移與雙色邊緣色散，重現水滴與液態玻璃的彎曲折光。

TL;DR 一句話核心觀念

CSS backdrop-filter: blur() 只會就地混色模糊，無法彎折背景線條；透過 SVG <feDisplacementMap> 讀取 R/G 通道偏移量將背景像素推離原本位置，再替玻璃倒角疊加極細微「青藍＋暖紅」邊緣色散光環，即可刻畫出凹凸曲面的液態折射感。

🧩 核心觀念拆解

TECHNIQUE 01

為什麼 blur() 不等於物理折射？

  • 原地模糊 vs 座標位移：高斯模糊把相鄰像素平均化，背後的斜線不會轉彎；實體透鏡則依表面曲率將像素推離原本座標。
  • SVG 置換公式：讀取 xChannelSelector="R" 與 yChannelSelector="G" 貼圖值（以中性灰 0.5 為基準），依 scale 計算偏移。
P'(x,y) = P(
  x + scale * (R(x,y) - 0.5),
  y + scale * (G(x,y) - 0.5)
)
TECHNIQUE 02

低頻曲面濾鏡與參數對照

  • 頻率必須拉低：與 Unit 01 消弭色帶的微觀雜訊（baseFrequency: 0.85）不同，曲面折光要使用低頻 0.015 ～ 0.045。
  • 強度建議區間：UI 卡片微折射建議 scale: 8 ～ 28；液態透鏡舞台展示可調至 40 ～ 60。
<feTurbulence type="fractalNoise"
  baseFrequency="0.025" numOctaves="2" />
<feDisplacementMap scale="24"
  xChannelSelector="R"
  yChannelSelector="G" />
TECHNIQUE 03

稜鏡邊緣色散與跨瀏覽器實戰

  • 牛頓三稜鏡效應：藍光與紅光波長折射率不同，厚玻璃斜邊會閃出微弱的青藍光與洋紅光錯位邊緣。
  • 零額外 GPU 負擔技法：利用 inset 2px 0 rgba(56,189,248,0.48) 搭配 inset -2px 0 rgba(244,63,94,0.3) 模擬色散邊，Chrome / Safari / Firefox 100% 通用。
box-shadow:
  inset 2px 0 3px rgba(56,189,248,0.48),
  inset -2px 0 3px rgba(244,63,94,0.30),
  inset 0 1px 0 rgba(255,255,255,0.85);

⚠️ 常見誤區與效能地雷：別把大範圍文字區也拿來強烈置換！

部分開發者誤將 scale="80" 的 SVG 置換直接套在閱讀文章本體上，結果導致文字筆畫斷裂、跨瀏覽器相容度不一且吃光行動裝置 GPU。正確工程做法：內文容器維持標準 blur(20px) saturate(190%)＋雙色 inset 色散光緣，只將真正的 <feDisplacementMap> 套用在背景光學圖騰或局部透鏡層。

📝 隨堂自我檢測（3 題）

      

        

          
Q1. 為何想呈現「玻璃將後方線條彎曲推開」的效果，不能只靠 CSS blur()，而需要 SVG <feDisplacementMap>？

          

            
            
            
            
          

          
✅ 解析（正解：A）：高斯模糊只做鄰域色彩平均，線條中心仍在原處；置換濾鏡則依 R/G 色版計算 $P'(x,y)$ 座標位移，模擬真實光線偏折。

        


        

          
Q2. 若分別要製作「消弭色帶微粒」與「大片水波曲面折射」，baseFrequency 應該如何區分？

          

            
            
            
            
          

          
✅ 解析（正解：B）：頻率越高顆粒越細（`0.85` 呈現磨砂霧粒），頻率越低波長越寬（`0.015～0.045` 呈現滑順玻璃曲率）。

        


        

          
Q3. 實作真實玻璃的「邊緣色散光環（Chromatic Dispersion）」時，在顧及文字可讀性與效能下，最推薦的實作策略為何？

          

            
            
            
            
          

          
✅ 解析（正解：B）：邊緣色散集中在高曲率切角邊緣；利用雙色 inset 內陰影可零濾鏡開銷呈現色散美感並確保內文絕對清晰。
