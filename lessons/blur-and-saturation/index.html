背景模糊、鮮豔度補償與玻璃微觀雜訊

告別灰濁廉價的半透明霧面——結合 blur(20px) saturate(190%) 與 SVG Noise Data URI 打造 Apple 級通透質感。

TL;DR 一句話核心觀念

單純套用 backdrop-filter: blur(20px) 會把底層相鄰像素混成一片死氣沉沉的灰濁色；唯有加上 saturate(180%～190%) 補償色彩鮮豔度，再疊加 2%～4% 不透明度的 SVG 微觀雜訊 消弭漸層色階斷裂，才能重現 Apple 系統介面那種清亮、溫潤且具實體磨砂觸感的毛玻璃。

🧩 核心觀念拆解

TECHNIQUE 01

為什麼單純用 blur() 會讓玻璃發灰？

  • 像素平均化的副作用：高斯模糊會將底層高對比與互補色像素加權平均，混合後彩度急速下降，呈現灰濁髒污感。
  • 彩度補償公式：在模糊後方接上 saturate(180%～190%)，強迫拉高透出底層的色彩飽和度，同時加上 -webkit-backdrop-filter 支援 Safari。
backdrop-filter: blur(20px) saturate(190%);
-webkit-backdrop-filter: blur(20px) saturate(190%);
TECHNIQUE 02

表面微透光對角漸層基底

  • 避免扁平純色：純粹填寫單一 rgba(255,255,255,0.2) 會讓面板像一塊廉價霧面塑膠片。
  • 135° 受光漸層：模擬左上環境光照射，左上端設為 0.25 白色微光，向右下平滑遞減至 0.05，賦予材質受光方向。
background: linear-gradient(
  135deg,
  rgba(255, 255, 255, 0.25) 0%,
  rgba(255, 255, 255, 0.05) 100%
);
TECHNIQUE 03

玻璃微觀雜訊（SVG Noise Data URI）

  • 消弭色階斷裂（Banding）：8-bit 螢幕在大面積柔和漸層與高模糊處會出現階梯狀色帶。
  • 2%～4% 磨砂粒子：透過內嵌 SVG feTurbulence 濾鏡產生噪點並將不透明度調低至 0.02～0.04，零網路請求即可注入細膩的實體玻璃觸感。
background-image: url("data:image/svg+xml,...");
opacity: 0.03;

⚠️ 常見誤區：背景是一片純白或純黑時，為何看不到毛玻璃？

毛玻璃的美感來自「對背後高對比色彩的模糊折射」。如果頁面底層是單調純白或全黑，就算設到 blur(30px) saturate(200%) 也完全看不出通透感；必須像本知識庫一樣，在底層配置飽滿的極光漸層或幾何色彩圖形作為光源折射母體。

Q1. 為何實作高質感毛玻璃時，常搭配 backdrop-filter: blur(20px) saturate(180%) 而不是只寫 blur(20px)？

          

            
            
            
            
          

          

            ✅ 解析（正解：B）：高斯模糊把相鄰不同色相像素平均後會降低彩度；加上 saturate(180%～190%) 能拉回透出色彩的鮮豔度。
          

        


        

          
Q2. 在玻璃面板中加入內嵌 SVG Noise Data URI（不透明度約 2%～4%）的主要作用為何？

          

            
            
            
            
          

          

            ✅ 解析（正解：B）：極微弱（2%～4%）的高頻雜訊能打散漸層色帶，並模擬真實物理磨砂玻璃的細微顆粒感。
          

        


        

          
Q3. 為何實作蘋果或 Vista 風格毛玻璃時，必須加上 -webkit-backdrop-filter 前綴並使用對角 linear-gradient 基底？

          

            
            
            
            
          

          

            ✅ 解析（正解：A）：Safari 仰賴 -webkit-backdrop-filter，而 135° 對角線漸層能替玻璃表面建立自然的環境光源方向。
