SLIDE 02 ・ 新手四大痛點 先釐清問題，再學配方

為什麼自己寫的毛玻璃總是「灰濁、扁平又卡頓」？

❌ 痛點 1 & 2：視覺髒灰與塑膠感

  • 灰灰髒髒：只寫 blur(20px) 沒做彩度補償，顏色被混成水泥灰。
  • 扁平像透明貼紙：四邊框亮度相同，缺乏左上迎光倒角與 1px 厚度。

❌ 痛點 3 & 4：看不清字與手機卡頓

  • 背景干擾讀字：缺少白色防護光暈與足量白霧底色，字糊成一團。
  • 滑不動掉幀：玻璃裡面又嵌小毛玻璃，瞬間超支 GPU 渲染預算。

SLIDE 03 ・ 光學基底（一） UNIT 01

拯救發灰毛玻璃：為什麼必須加上 saturate(190%)？

💡 比喻：只用模糊就像隔著「起霧又積灰」的窗戶；加上 saturate(190%) 就像擦亮玻璃，讓彩光重新透出來。

核心機制與參數

  • 彩度衰減 32%～45%：高斯模糊會將互補色像素平均，色彩濃度大幅下滑。
  • 黃金配方：backdrop-filter: blur(20px) saturate(190%)（搭 -webkit-）。
  • 斜向基底漸層：使用 135deg 從 0.25 → 0.05 透光，且背後需有豐富色彩。
❌ 僅 blur(20px)
彩度流失約 32%～45%，面板混成灰霧色。
✅ + saturate(190%)
背後藍青極光飽滿透亮，展現通透光澤！ 
backdrop-filter: blur(20px) saturate(190%);
background: linear-gradient(135deg, rgba(255,255,255,0.25), rgba(255,255,255,0.05));

SLIDE 04 ・ 光學基底（二） UNIT 01

消除漸層條紋：為什麼要疊 3.2% SVG 微觀雜訊？

💡 比喻：就像在玻璃表面噴一層極細磨砂微粒，打散螢幕等高線條紋（Banding）。

8-bit 色階斷裂與 Dithering

  • 漸層色帶：8-bit 螢幕僅 256 階亮度，緩變霧面易見條紋。
  • 內嵌 SVG：baseFrequency="0.85" 免外部圖檔請求。
  • 2%～4% 區間：鎖定 0.032；超過 8% 易產生雪花噪點。
.glass-panel::after {
  content: "";
  position: absolute; inset: 0;
  opacity: 0.032; /* 2%～4% */
  pointer-events: none;
}

SLIDE 05 ・ 表面折射（一） UNIT 02

做出 2mm 玻璃厚度：左上倒角與 1px 內陰影

💡 比喻：陽光從左上方 45 度照下——玻璃只有「上緣與左側」切面會亮出反光！

三層邊緣厚度公式

  • 不對稱外框：頂邊 0.7、左邊 0.5 明顯亮於右下（0.2）。
  • 1px 剖面高光：inset 0 1px 0 畫出玻璃頂部切角閃線。
  • 景深外陰影：0 20px 40px 推開面板懸浮感。
border: 1px solid rgba(255,255,255,.2);
border-top-color: rgba(255,255,255,.7);
border-left-color: rgba(255,255,255,.5);
box-shadow: 0 20px 40px rgba(0,0,0,.2),
  inset 0 1px 0 rgba(255,255,255,.8),
  inset 0 -1px 0 rgba(0,0,0,.1);

SLIDE 06 ・ 表面折射（二） UNIT 02

Vista Aero 靈魂：50% 鏡面反光切面與 .vista-text 護眼圈

上半部 50% 鏡面反射階躍

  • 非連續光斑切線：::before 設 height: 50%，白光從 0.4 → 0.05 在半高突然收束，重現平滑玻璃鏡面反光。
  • 防呆鐵則：必加 pointer-events: none;，否則上半部按鈕全會點擊失靈！

.vista-text 雙層白色防護光暈

  • 保護深色字（#1c1c1e）：即使背後的極光滑過深藍區塊，標題字周圍依舊自帶柔白護盾。
  • 雙層發光公式：0 0 8px rgba(255,255,255,0.9), 0 0 16px rgba(255,255,255,0.5)。

SLIDE 07 ・ 進階光學折射 UNIT 04

讓背景線條彎曲折射：SVG 置換與稜鏡色散

💡 比喻：blur() 只把水底弄霧；<feDisplacementMap> 才像凹凸透鏡把直線推彎並閃出青紅邊光！

置換頻率與色散指南

  • 座標偏移：依 R/G 通道與 0.5 差值乘 scale 推移像素。
  • 低頻波紋：水面曲率用 0.015～0.045，UI 微折射 8～28。
  • 雙色色散：用青藍 0.48 ＋ 暖紅 0.30 內陰影護住文字銳利度。
<feTurbulence baseFrequency="0.024" />
<feDisplacementMap scale="24"
  xChannelSelector="R" yChannelSelector="G" />
box-shadow:
  inset 2px 0 3px rgba(56,189,248,.48),
  inset -2px 0 3px rgba(244,63,94,.30);

SLIDE 08 ・ 動態追光互動 UNIT 05

Apple Liquid Glass 動態反光：讓滑鼠變成手電筒

--mx / --my 與遮罩透邊

  • 局部座標寫入：pointermove 寫入 --mx、--my，並提供 50%, 20% 預設值照顧手機用戶。
  • Border-Mask 感光：透過 mask-composite: exclude 挖空內部，只讓外圍 1.5px 倒角跟隨游標閃耀。
  • 零 Reflow 節流：結合 requestAnimationFrame 將腳本耗時壓低至 < 0.5ms。

SLIDE 09 ・ 效能預算守則 UNIT 03

別讓手機卡死！守住 16.67ms 的「外實內輕」架構

💡 比喻：每個 backdrop-filter 都是一位每 1/60 秒就得重畫後方風景的畫師；在玻璃裡嵌套 3 個模糊標籤，畫師立刻暴增為 4 倍！

Chromium RenderPass 與幀預算

  • 每幀極限 16.67ms：維持 60fps 必須在 16.67 毫秒內完成採樣＋卷積；超過 24ms 即出現掉幀 Jank。
  • 嵌套雪崩：20 張卡片若各自嵌套 3 個模糊小膠囊，真實 GPU 模糊節點數會翻倍至 80 個。

解法：外實內輕 + AGENTS.md

  • 外層真模糊、內層半透明實底：次級小卡片改用 rgba(255, 255, 255, 0.58)，額外模糊成本降為零！
  • 寫進專案憲法：鎖定在 AGENTS.md，防止 AI 每次擴充都偷偷嵌套模糊。

SLIDE 10 ・ 無障礙與退場機制 UNIT 06

漂亮更要人人讀得懂：WCAG 4.5:1 與雙重安全傘

WCAG 2.2 相對亮度紅線

  • 一般內文底線：必須達 4.5 : 1（AA 級），大標題為 3.0:1，醫療／高齡 AAA 級為 7.0:1。
  • 別只賭光暈：閱讀卡白霧濃度應設 0.58～0.75 先站穩底線，不能只靠 .vista-text。
/* 安全傘 1：尊重系統輔助「減少透明度」 */
@media (prefers-reduced-transparency: reduce) {
  .glass-panel { backdrop-filter: none; background: rgba(248,250,252,0.94); }
}
/* 安全傘 2：舊瀏覽器不支援背景模糊時保底 */
@supports not (backdrop-filter: blur(1px)) {
  .glass-panel { background: rgba(248,250,252,0.90); }
}
