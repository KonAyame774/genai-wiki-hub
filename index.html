五大光學技巧 對應 CSS 核心屬性
1. 模糊＋鮮豔補償 backdrop-filter: blur(20px) saturate(190%) 拯救發灰濁背景
2. 物理厚度倒角 border-top/left 高亮＋inset 0 1px 0 1px 高光切角
3. Vista 鏡面切面 ::before 設 height: 50% 非連續漸層切出反射分界線
4. 文字防護光暈 .vista-text 雙層白光 text-shadow 確保可讀性
5. 微觀雜訊＋效能 3% SVG Noise 消弭色帶；內層元件禁嵌套模糊保 60fps
💎 AGENTS.md 基準 `.glass-panel` 程式碼 
.glass-panel {
  position: relative;
  width: 400px;
  padding: 24px;
  border-radius: 16px;
  overflow: hidden;

  /* 1. 表面微透光基底 */
  background: linear-gradient(
    135deg,
    rgba(255, 255, 255, 0.25) 0%,
    rgba(255, 255, 255, 0.05) 100%
  );

  /* 2. 毛玻璃與彩度增強（核心） */
  backdrop-filter: blur(20px) saturate(190%);
  -webkit-backdrop-filter: blur(20px) saturate(190%);

  /* 3. 光學倒角：頂部左側亮，底部右側暗 */
  border: 1px solid rgba(255, 255, 255, 0.2);
  border-top-color: rgba(255, 255, 255, 0.7);
  border-left-color: rgba(255, 255, 255, 0.5);

  /* 4. 實體厚度與陰影 */
  box-shadow:
    0 20px 40px rgba(0, 0, 0, 0.2),
    inset 0 1px 0 0 rgba(255, 255, 255, 0.8),
    inset 0 -1px 0 0 rgba(0, 0, 0, 0.1);
}

.glass-panel::before {
  content: "";
  position: absolute;
  top: 0; left: 0; right: 0;
  height: 50%;
  background: linear-gradient(
    180deg,
    rgba(255, 255, 255, 0.4) 0%,
    rgba(255, 255, 255, 0.05) 100%
  );
  pointer-events: none;
}

.vista-text {
  color: #1c1c1e;
  font-weight: 600;
  text-shadow:
    0 0 8px rgba(255, 255, 255, 0.9),
    0 0 16px rgba(255, 255, 255, 0.5);
}
