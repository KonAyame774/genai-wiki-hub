## Slide 02｜新手痛點：為什麼自己的毛玻璃「灰濁、扁平又卡頓」？
- **引用來源**：`card-01`、`card-02`、`card-03`（Unit 01–03）
- **4 大常見踩雷盲點**：
  - 1. **發灰混濁**：只寫 `blur(20px)` 忘了補回飽和度，彩度被互補色洗灰。
  - 2. **扁平像塑膠**：四邊框透明度一樣，沒有左上迎光倒角與 1px 厚度陰影。
  - 3. **背景干擾讀字**：沒有白色防護光暈與對比底色，深背景讓字糊掉。
  - 4. **手機滑不動掉幀**：玻璃內層又嵌套多層模糊，超支 GPU `16.67ms` 預算。

## Slide 03｜光學基底（一）：高斯模糊與 `saturate(190%)` 鮮豔度補償
- **引用來源**：`card-01`（Unit 01 / `raw/01`）
- **生活比喻**：純模糊就像隔著沾灰塵的霧玻璃；補上 `saturate(190%)` 就像把玻璃擦亮，讓背後色彩重新透光。
- **核心重點與數據**：
  - 高斯模糊把相鄰互補色平均，會讓有效彩度大幅衰減 **32%～45%**。
  - 黃金配方：`backdrop-filter: blur(20px) saturate(190%)`（搭配 `-webkit-` 前綴）。
  - 表面基底改用 `135deg` 斜向漸層（左上 `0.25` → 右下 `0.05`）取代死板純白。
  - 背後必須有豐富彩色極光或圖形，純白/純黑底看不到折射層次。

## Slide 04｜光學基底（二）：`3.2%` SVG 微觀磨砂雜訊消弭色階斷裂
- **引用來源**：`card-01`（Unit 01 / `raw/03`）
- **生活比喻**：像替平滑玻璃噴上極細微的「防眩光磨砂霧粒」，人眼察覺不到顆粒，卻能打散難看的等高線條紋。
- **核心重點與數據**：
  - 8-bit（0～255 階）螢幕在顯示大面積半透明漸層時容易出現 **色階斷裂（Banding）**。
  - 以內嵌 SVG Data URI `<feTurbulence type="fractalNoise" baseFrequency="0.85" />` 產生高頻細砂紋理。
  - 不透明度鎖定在 **`2%～4%`**（本知識庫標準值 **`0.032`**），零外部圖檔 HTTP 請求。
  - 警語：雜訊若超過 `8%` 會出現老舊電視雪花點，造成閱讀疲勞。

## Slide 05｜表面折射（一）：物理厚度、光學倒角與 `inset` 高光
- **引用來源**：`card-02`（Unit 02 / `raw/02`）
- **生活比喻**：假設天空光源從左上方 45 度照下來——玻璃切割斜邊只有「朝上、朝左」那一側會反光發亮！
- **核心重點與數據**：
  - 頂部迎光邊：`border-top-color: rgba(255, 255, 255, 0.7)`；左側邊：`0.5`；右下背光維持 `0.2`。
  - 1 像素物理切角：`inset 0 1px 0 0 rgba(255, 255, 255, 0.8)`（上亮邊）＋ `inset 0 -1px 0 0 rgba(0, 0, 0, 0.1)`（下壓暗）。
  - 外側大陰影：`0 20px 40px rgba(0, 0, 0, 0.2)` 推開景深讓面板懸浮空中。

## Slide 06｜表面折射（二）：Vista `::before` 50% 鏡面切面與 `.vista-text`
- **引用來源**：`card-02`（Unit 02 / `raw/02`）
- **核心重點與數據**：
  - `.glass-panel::before` 設定 **`height: 50%`** 與垂直白霧漸層（`0.4 → 0.05`），在半高處做出經典非連續鏡面反光分界線。
  - 必加防呆鐵則：偽元素必須加上 **`pointer-events: none;`**，否則卡片上半部按鈕會點不到！
  - `.vista-text` 雙層白光保護：`text-shadow: 0 0 8px rgba(255,255,255,0.9), 0 0 16px rgba(255,255,255,0.5)`，保護深字不懼彩底干擾。

## Slide 07｜進階表面折射：SVG `<feDisplacementMap>` 與邊緣色散
- **引用來源**：`card-04`（Unit 04 / `raw/03`）
- **生活比喻**：`blur()` 只是把水底風景弄霧；`<feDisplacementMap>` 則是拿一片凹凸放大鏡，真正把背景直線推彎並映出稜鏡彩虹邊！
- **核心重點與數據**：
  - 置換原理：$P'(x,y)$ 依貼圖 R/G 通道減去中性灰 `0.5` 後乘上 `scale` 推移像素座標。
  - 參數對照：大面積曲面波紋須改用低頻 `baseFrequency: 0.015～0.045`，UI 微折射 `scale: 8～28`。
  - 邊緣色散實戰：利用雙色 `inset` 內陰影（青藍 `0.48` ＋ 暖紅 `0.30`）於 1px～3px 邊緣模擬稜鏡色散，100% 跨瀏覽器且清晰。

## Slide 08｜動態光學互動：游標座標 `--mx` / `--my` 即時光源追蹤
- **引用來源**：`card-05`（Unit 05 / `raw/04`）
- **生活比喻**：把滑鼠游標當成小手電筒——滑鼠靠近哪一邊，卡片表面和 `1.5px` 玻璃邊框就跟著被點亮。
- **核心重點與數據**：
  - JS 監聽 `pointermove` 並將局部座標寫入 `--mx`、`--my`（務必預設 `50%`、`20%` 照顧手機無滑鼠體驗）。
  - 利用 `mask-composite: exclude` 挖空 `content-box`，只讓邊角發光不遮蔽內文。
  - 效能守則：搭配 `requestAnimationFrame` 節流（`< 0.5ms`），不改幾何 `top/left` 以維持零 Reflow。

## Slide 09｜效能工程：GPU 合成圖層瓶頸與 60fps「外實內輕」守則
- **引用來源**：`card-03`（Unit 03 / `raw/05`）
- **生活比喻**：每個 `backdrop-filter` 都是一名得即時重繪後方風景的畫師；在玻璃裡又嵌小玻璃，畫師工作量暴增 4 倍，手機瞬間掉幀！
- **核心重點與數據**：
  - 60Hz 顯示器每幀運算預算上限僅 **`16.67ms`**（超過 `24ms` 即視為明顯掉幀 Jank）。
  - 嵌套 3 個模糊子膠囊會讓 20 張卡片暴增成 **80 個真實模糊節點**（4 倍負荷）。
  - **外實內輕鐵則**：只有外層 `.glass-panel` 跑即時模糊；內部子卡改用高通透實底 `rgba(255, 255, 255, 0.58)`，並寫進 `AGENTS.md`。

## Slide 10｜無障礙設計：WCAG `4.5:1` 對比度與雙重降級防線
- **引用來源**：`card-06`（Unit 06 / `raw/06`）
- **核心重點與數據**：
  - **WCAG 2.2 對比底線**：一般內文須達 **`4.5 : 1`**（AA 級），大標題 `3.0 : 1`，加強版 AAA 級 `7.0 : 1`。
  - 不可只靠 `.vista-text` 光暈，內層閱讀卡須墊高白霧底色穩守 `4.5:1`。
  - 第一安全傘：`@media (prefers-reduced-transparency: reduce)` 關閉模糊並拉實底色至 `0.94`。
  - 第二安全傘：`@supports not (backdrop-filter: blur(1px))` 退場至 `0.90` 霧白底，防舊環境破圖。

## Slide 12｜總結：介面光學 5 大口訣與 6 大互動實驗室傳送門
- **引用來源**：`card-01` ～ `card-06`（Unit 01–06 全覆蓋）
- **新手設計 5 句速記口訣**：
  - 1. 模糊加 **`saturate(190%)`** 救回鮮豔度，疊 **`3.2%`** 雜訊消色帶。
  - 2. 左上亮邊 ＋ `inset` 1px 做出厚度，**`50%`** 切面要加 `pointer-events: none`。
  - 3. 曲率偏折用 **`feDisplacementMap`**，動態互動靠 `--mx`/`--my`。
  - 4. 死守 **`16.67ms`** 幀預算與「外實內輕」，嚴禁嵌套 `backdrop-filter`。
  - 5. 內文穩守 **`4.5:1`** 並配備 `prefers-reduced-transparency` 安全傘。
